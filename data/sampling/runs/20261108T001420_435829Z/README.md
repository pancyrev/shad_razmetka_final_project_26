# Отбор фотографий 8 ноября 2026 года

Из [700 кандидатов CC0](candidates_from_api.jsonl) отобраны [400 основных фотографий](../../../golden_400/photos.jsonl) и [100 для подготовки исполнителей](../../../reference_100/photos.jsonl). В архиве сохранены [назначения всех кандидатов](selection_500_proposal.csv), [результаты скачивания и SHA-256 оригиналов](download_audit.jsonl), [пары на проверку сходства](similarity_review.csv) и [сводный аудит](sampling_audit.json).

Заданные в сводном аудите SHA-256 для `main_sha256` и `worker_sha256` относятся к двум указанным выше манифестам. Поле `local_path` в аудите описывает каталог исходного запуска. В день отбора проверены 500 различных контрольных сумм, среди выбранных фотографий обнаружено 0 пар с расстоянием dHash не выше 4. Статус `visual_review_pending` зафиксирован на этапе технического отбора. Результат последующей проверки разметки хранится с [итоговыми рамками](../../../golden_400/README.md).
