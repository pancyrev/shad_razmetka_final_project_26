# Итоговая разметка 400 фотографий

[Манифест](photos.jsonl) фиксирует ID и ссылки на фотографии. В [разметке](annotations.jsonl) содержится 241 рамка, нормализованная по ширине и высоте снимка. В [галерее](../../docs/final_annotations_400.html) фотографии можно посмотреть с наложенными рамками.

[Результаты независимой проверки](review.jsonl) соединяются с разметкой по `photo_id`. Поле `status` хранит ответ разметчика, `annotation_source` сохраняет источник финального ответа, `review.votes` содержит число голосов каждого вида, а `review.majority` — вердикт большинства. Эти четыре поля восстановлены из `golden set/dataset.jsonl` в коммите `a734bf9`. Для каждой фотографии сверены URL и координаты с текущим файлом разметки.

| Источник финального ответа | Фото | Большинство OK | Большинство BAD |
| --- | ---: | ---: | ---: |
| Исходная разметка (`original_review_accepted`) | 357 | 357 | 0 |
| Повторная разметка (`reannotation_43`) | 43 | 8 | 35 |
| Всего | 400 | 365 | 35 |

Все 43 повторных ответа вошли в финальный набор, включая 35 с отрицательным вердиктом. При подсчёте статусов 220 изображений имеют `FOUND`, 179 — `NONE`, одно — `UNCERTAIN`. У последнего список рамок пуст, а присутствие бабочки осталось неопределённым.
