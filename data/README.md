# Данные проекта

| Набор | Состав и назначение | Файлы |
| --- | --- | --- |
| Основные 400 | Фотографии iNaturalist с лицензией CC0, использованные для крауд-разметки и оценки моделей | [Фото](golden_400/photos.jsonl), [рамки](golden_400/annotations.jsonl), [голоса ревьюеров](golden_400/review.jsonl), [пояснения](golden_400/README.md) |
| Отдельные 100 | Фотографии CC0 и эталонные рамки для подготовки исполнителей и подбора настроек моделей | [Фото](reference_100/photos.jsonl), рамки в двух форматах — [JSONL](reference_100/annotations.jsonl) и [исходный JSON-массив](reference_100/worker_reference_first_pass.json) |
| Конкурсные 400 | Список организаторов для получения предсказаний | [Фото](contest_400/photos.jsonl), [шаблон посылки](contest_400/submission-template.jsonl) |

В каждом манифесте одна строка на фотографию. Поле `photo_id` связывает таблицы, `photo_url` указывает на оригинал, а в `annotations.jsonl` координаты рамок заданы полями `left`, `top`, `width`, `height` в долях ширины и высоты. В учебном наборе 58 фотографий с бабочками, 42 без рамок, всего 61 рамка.

История формирования выборки включает [план](sampling/sampling_plan.json) и [запуск 8 ноября](sampling/runs/20261108T001420_435829Z/README.md). Отбор из зафиксированных кандидатов воспроизводится локально. Оригиналы восстанавливаются по сохранённым URL. Для просмотра без сети открывайте [галерею основных 400](../docs/final_annotations_400.html) или [галерею эталонных 100](../docs/reference_100.html).
