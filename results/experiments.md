# Эксперименты с детекторами бабочек

На итоговых 400 размеченных фотографиях Gemma 4 12B получила F1 **0,854** при IoU ≥ 0,5. При IoU ≥ 0,75 лучший результат у Grounding DINO — **0,501**. Для каждой модели сохранены предсказания по всем кадрам и метрики. [Итоговый отчёт](final_400/README.md)

| Эксперимент | Что показала проверка |
| --- | --- |
| Исходные настройки четырёх моделей | На 100 фотографиях подавление пересекающихся рамок OWLv2 при NMS IoU = 0,5 повысило F1 с 0,513 до 0,591. [Сравнение](experiments/validation_2026-11-13/README.md) |
| Подбор промптов Qwen и Gemma | На тех же 100 фотографиях проверили по десять запросов. Лучшие промпты дали F1 0,474 у Qwen и 0,950 у Gemma. [Протокол и результаты](experiments/prompt_search_2026-11-15/README.md) |
| Ответ только с координатами | Упрощённый JSON повысил F1 Qwen до 0,526, у Gemma после уточнения запроса F1 составила 0,931. [Эксперимент с форматом](experiments/boxes_only_2026-11-16/README.md) |
| Возврат полного формата JSON | Все 200 предсказаний Qwen и Gemma при повторном запуске совпали с результатами выбранных промптов. [Проверка повтора](experiments/restored_task_record_2026-11-16/README.md) |
| Переименование выборок | У прежнего и нового наборов совпали ID, байты изображений и рамки на всех 500 размеченных фото. Четыре модели дополнительно проверили на четырёх кадрах из каждого набора. [Отчёт миграции](experiments/split_migration_2026-11-16/README.md) |

В исторических конфигурациях, логах и JSON сохранены имена, действовавшие во время запуска. Прежний HF `validation` теперь называется `train` (100 фото), прежний `test` — `validation` (400 фото). Нынешний `test` содержит отдельные конкурсные изображения. [Инструкция по воспроизведению](../docs/reproduce.md)
