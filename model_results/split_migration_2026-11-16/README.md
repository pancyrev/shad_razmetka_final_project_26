# Проверка после переименования HF split

Датасет: `xartik/inaturalist_butterflies`, новая ревизия
`863f76cfbcbcaf1563693b8a08e5128efa47a4c4`.

| Новый split | Прежний split | Изображений | Эталонных рамок | Без бабочек |
| --- | --- | ---: | ---: | ---: |
| train | validation | 100 | 61 | 42 |
| validation | test | 400 | 241 | 180 |

Новый `test` с конкурсными фотографиями без разметки не загружался и не использовался.
Для сравнения использовались только локально закэшированные файлы старой ревизии
`1316e3c7147d4399a03f90684e191aae4d798f09`.

## Что изменено

- В CLI по умолчанию оценивается размеченный `validation` из 400 изображений.
- Подбор промптов использует только закреплённый `train` из 100 изображений;
  результаты новых запусков сохраняются в `model_results/prompt_search_train`.
  Старые отчёты, ревизии и имена split в исторических артефактах сохранены.
- В демо по умолчанию выбран `train`, ревизия закрепляется после загрузки данных.
  Доступны `train` и `validation`; конкурсный `test` в демо пока отключён.
- `mode=test` требует эталонные рамки. Отсутствующая разметка и `null` вызывают
  явную ошибку; пустой массив остаётся корректным отрицательным примером.
  `mode=inference` не использует эталоны и не считает метрики по ним.
- Промпты, веса и настройки выбранных моделей сохранены.

## Проверки

1. Все 500 размеченных изображений открыты; порядок ID, байты изображений и рамки
   полностью совпали с прежними выборками. Train и validation не пересекаются.
   Подробности: [dataset_check.json](dataset_check.json), [train.json](train.json),
   [validation.json](validation.json); воспроизведение — [prepare_data.py](prepare_data.py).
2. Пройдены 39 автоматических тестов и Ruff. Проверки данных без разметки используют
   синтетические записи, не конкурсную выборку. Проверен запрет использования
   нынешних validation/test для подбора промптов.
3. Все четыре модели последовательно проверены на CUDA: по четыре изображения
   из каждой размеченной выборки, включая отрицательные и несколько бабочек.
   Восемь запусков завершились без технических ошибок; все 32 итоговые записи
   точно совпали с прежними предсказаниями на соответствующих фотографиях.
   Конфиги, ответы, метрики и ссылки Comet находятся в каталогах
   [train](train) и [validation](validation), сравнения — в `regression.json`.
4. Режим inference проверен на четырёх изображениях train с OWLv2: эталоны
   игнорируются, метрики по разметке отсутствуют, JSONL создан без ошибок.
   Артефакты: [inference_train/owlv2](inference_train/owlv2).
5. Все пять кодовых ячеек [демо-ноутбука](../../03_model_demo.ipynb) выполнены:
   Grounding DINO, четыре изображения train, ошибок нет.
   Проверка и ссылка Comet: [notebook_check.json](notebook_check.json).

Сводка запусков и ссылки Comet: [summary.json](summary.json).
Драйвер проверок: [smoke.py](smoke.py); выполнение демо: [execute_demo.py](execute_demo.py).
Оба процесса использовали общую GPU-блокировку `/tmp/butterfly-prompt-search-gpu.lock`.
После проверок GPU освобождена от этих моделей, на диске оставалось около 14 ГиБ.

Это проверка работоспособности после переименования, а не новая полная оценка
качества. Полный прогон четырёх моделей на тех же 400 размеченных изображениях
сохранён в [историческом отчёте](../test_2026-11-16/README.md), где эта выборка
называлась `test`. Повторный полный подбор двадцати промптов не запускался.
