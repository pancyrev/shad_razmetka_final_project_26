# Итоговые четыре модели на HF test (400 изображений)

Конфигурации выбраны по validation и зафиксированы в `frozen/` до чтения test. На test не подбирались промпты, пороги, NMS или параметры генерации. Это один итоговый прогон каждой из четырёх моделей.

Источник: `xartik/inaturalist_butterflies`, split `test`, revision `1316e3c7147d4399a03f90684e191aae4d798f09`. Проверены все 400 изображений, 241 эталонная рамка, 180 отрицательных изображений. Пересечений с 100 validation ID нет. Сиды фиксированы (seed=42); модели запускались по очереди под общей flock-блокировкой.

## Артефакты и проверка

`plan.json` фиксирует момент выбора, исходные validation-прогоны и SHA256 кода/конфигов. `dataset.json` содержит ревизию, SHA256 Parquet и точный порядок ID; `ground_truth.jsonl` — эталоны из HF. В каталогах моделей сохранены конфиги, ответы всех попыток, итоговые предсказания, метрики, тайминги, GPU metadata и Comet URL. Submission создаётся только при отсутствии окончательных отказов.

`audit_results.py` независимо повторяет парсинг и валидацию, проверяет координаты детекторов, NMS, сид каждой попытки, промпты с feedback, совпадение frozen-конфигов с validation, отсутствие пересечения ID и соответствие эталонов HF Parquet. Метрики пересчитаны по финальным рамкам. GPU-журналы подтверждают отсутствие пересечения запусков. Итог — `audit.json`.

```bash
.venv/bin/python model_results/test_2026-11-16/audit_results.py
.venv/bin/python model_results/test_2026-11-16/verify_comet.py
```

`run_evaluation.py prepare` фиксирует выбор до теста, `preflight` загружает и проверяет данные, действия owlv2/grounding_dino/qwen/gemma запускают отдельные модели. Все четыре действия запускались последовательно под `flock /tmp/butterfly-prompt-search-gpu.lock`. Существующие результаты защищены от перезаписи; для нового запуска нужны новые output_dir. Исходный пайплайн и промпты при этой оценке не изменялись.
