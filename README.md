# Финальный проект ШАД: разметка бабочек

Репозиторий команды для отбора фотографий iNaturalist, разметки бабочек рамками, проверки разметки и сравнения моделей. Сейчас опубликован **шаг 01: сбор выборки**. Код создания проекта и пулов будет добавлен отдельными шагами; пулы пока не запускаются.

## Шаг 01. Собрать фотографии

Откройте `01_build_photo_manifests.ipynb` из корня репозитория и выполните ячейки по порядку. Входы: `sampling_plan.json`, конкурсные `dataset.jsonl` и `submission-template.jsonl`. Ноутбук запрашивает кандидатов через API iNaturalist, случайно выбирает фотографии из заданных групп с фиксированным `seed`, проверяет лицензию CC0 и оригиналы, затем записывает 400 фотографий для разметки и отдельные 100 фотографий для будущих обучающих, экзаменационных и контрольных заданий. Пересечения по ID и URL с конкурсным набором проверяются автоматически.

```bash
python -m pip install -r requirements-data.txt
```

Результаты каждого запуска сохраняются в `sampling_runs/<время запуска>/`. В репозитории есть пример запуска от 8 ноября 2026 года: два JSONL, список кандидатов, таблица отбора, HTML-галерея и аудит. Его статус — **технические проверки пройдены, визуальная проверка ожидается**. Списки пока не содержат эталонных рамок; 100 дополнительных фотографий ещё не распределены по типам заданий.

Исходные изображения загружаются локально в `images/` и не хранятся в Git. JSONL содержат публичные ссылки на оригиналы iNaturalist. Личные токены и `.env` в репозиторий не добавляются.
