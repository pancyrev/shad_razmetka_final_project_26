# Финальный проект ШАД: разметка бабочек

Репозиторий команды для отбора фотографий iNaturalist, разметки бабочек рамками, проверки разметки и сравнения моделей. В репозитории есть шаг 01 — сбор выборки и шаг 02 — первый проход разметки 100 фотографий для обучающих, экзаменационных и контрольных заданий. Код создания проекта и пулов будет добавлен отдельными шагами; пулы пока не запускаются.

## Шаг 01. Собрать фотографии

Откройте `01_build_photo_manifests.ipynb` из корня репозитория и выполните ячейки по порядку. Входы: `sampling_plan.json`, конкурсные `dataset.jsonl` и `submission-template.jsonl`. Ноутбук запрашивает кандидатов через API iNaturalist, случайно выбирает фотографии из заданных групп с фиксированным `seed`, проверяет лицензию CC0 и оригиналы, затем записывает 400 фотографий для разметки и отдельные 100 фотографий для будущих обучающих, экзаменационных и контрольных заданий. Пересечения по ID и URL с конкурсным набором проверяются автоматически.

```bash
python -m pip install -r requirements-data.txt
```

Результаты каждого запуска сохраняются в `sampling_runs/<время запуска>/`. В репозитории есть пример запуска от 8 ноября 2026 года: два JSONL, список кандидатов, таблица отбора, HTML-галерея и аудит. Его статус — **технические проверки пройдены, визуальная проверка ожидается**. Списки пока не содержат эталонных рамок; 100 дополнительных фотографий ещё не распределены по типам заданий.

Исходные изображения загружаются локально в `images/` и не хранятся в Git. JSONL содержат публичные ссылки на оригиналы iNaturalist. Личные токены и `.env` в репозиторий не добавляются.

## Шаг 02. Проверить ответы для обучения, экзамена и контроля

В `annotations/worker_reference_first_pass.json` и `annotations/worker_reference_first_pass.jsonl` сохранена разметка всех 100 отдельных фотографий: нормализованные рамки взрослых бабочек либо `boxes: []`. На 56 фотографиях предложено 59 рамок; на 44 взрослых бабочек нет. В `annotations/worker_reference_review_notes.json` отмечены случаи для приоритетной проверки.

Откройте `02_review_worker_reference.ipynb`: он проверяет состав ID, отсутствие пересечений с конкурсными и основными фотографиями, координаты рамок и показывает галерею с наложенными рамками. Результат пока является **первым проходом**. Перед использованием ответов для экзаменов и контрольных заданий второй участник команды должен независимо проверить каждую фотографию. Два снимка с бабочкой только на дисплее нужно отдельно разобрать и до решения не включать в экзамен или контроль. Разделение по ролям выполняется после проверки.
