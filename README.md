# Финальный проект ШАД: разметка бабочек

Репозиторий содержит материалы отбора фотографий iNaturalist и разметку взрослых бабочек рамками: два ноутбука, исходные списки фотографий, результаты проверок и HTML-галереи.

## Шаг 01. Формирование выборки

[01_build_photo_manifests.ipynb](01_build_photo_manifests.ipynb) получает кандидатов через публичный API iNaturalist по [плану отбора](sampling_plan.json). Конкурсные фотографии заданы в [dataset.jsonl](dataset.jsonl), их состав сопоставляется с [submission-template.jsonl](submission-template.jsonl).

Состав основной выборки и отдельного набора для материалов исполнителей задан квотами:

| Категория наблюдения | Для разметки и сравнения моделей | Для обучения и экзамена исполнителей |
| --- | ---: | ---: |
| Бабочки | 240 | 60 |
| Чешуекрылые, кроме бабочек | 60 | 15 |
| Другие насекомые | 50 | 13 |
| Астровые растения | 50 | 12 |
| **Итого** | **400** | **100** |

В основной выборке 60% фотографий отобраны из наблюдений бабочек, а остальные 40% распределены между группами, на которых проверяются ложные срабатывания:

- **Бабочки — 60%:** основной материал для проверки обнаружения объектов, полноты разметки и точности границ рамок.
- **Чешуекрылые, кроме бабочек — 15%:** внешне похожие насекомые; эта группа позволяет проверить, не выделяет ли модель объекты, исключённые правилами задания.
- **Другие насекомые — 12,5%:** проверка способности отличать бабочек от других насекомых и не создавать лишние рамки.
- **[Астровые растения](https://www.inaturalist.org/taxa/47604) — 12,5%:** цветочный фон для проверки ложных выделений цветков и частей растений, а также возможных бабочек на цветах.

В наборе из 100 фотографий для обучения и экзамена исполнителей сохранено близкое соотношение групп: 60%, 15%, 13% и 12%. Фотографии этого набора отделены от основной выборки и не используются для сравнения моделей.

Категория наблюдения определяет источник отбора, а наличие взрослой бабочки устанавливается по самому изображению. Например, наблюдение бабочки может содержать фотографию гусеницы, а на фотографии растения может присутствовать бабочка. Поэтому 60% наблюдений бабочек не означают 60% положительных ответов. Квоты задают состав проверочных сценариев; они не оценивают распространённость бабочек в природе.

Отбор выполняется случайно внутри заданных групп с фиксированным `seed`. Проверяются лицензия CC0, размеры и контрольные суммы оригиналов, уникальность ID и ссылок, отсутствие пересечений между выборками и с конкурсным набором. Для поиска визуально похожих пар используется dHash.

Результаты [запуска от 8 ноября 2026 года](sampling_runs/20261108T001420_435829Z/):

- получены 700 кандидатов с лицензией CC0;
- отобраны [400 основных фотографий](sampling_runs/20261108T001420_435829Z/main_dataset_draft.jsonl) и [100 отдельных фотографий для материалов исполнителей](sampling_runs/20261108T001420_435829Z/worker_training_exam_draft.jsonl);
- пересечений по ID и ссылкам между выборками и с конкурсным набором нет;
- проверены 500 оригиналов; побайтовых дубликатов и пар с расстоянием dHash не более 4 не обнаружено.

Каждая запись манифеста содержит `photo_id` и публичную ссылку `photo_url` на оригинал. Квоты групп, контрольные суммы и результаты проверок сохранены в [sampling_audit.json](sampling_runs/20261108T001420_435829Z/sampling_audit.json). Исходные изображения сохраняются локально в `images/`.

## Шаг 02. Проверка разметки

[02_review_worker_reference.ipynb](02_review_worker_reference.ipynb) сопоставляет разметку с исходным списком 100 фотографий, проверяет структуру записей, ID, ссылки и границы рамок, а также отображает фотографии с наложенной разметкой.

Разметка сохранена в [JSON](annotations/worker_reference_first_pass.json) и [JSONL](annotations/worker_reference_first_pass.jsonl):

- 100 фотографий: 58 с бабочками и 42 с пустым списком рамок;
- всего 61 рамка;
- ID и ссылки совпадают с исходным списком; пересечений с основной и конкурсной выборками нет;
- все рамки прошли проверку структуры и нормализованных координат.

Координаты `left`, `top`, `width` и `height` заданы относительно ширины и высоты оригинала. Рамки охватывают видимые крылья, тело, усики и лапки.

## Галереи

- [Размеченные фотографии](worker_reference_annotated_gallery.html): 100 встроенных изображений с 61 красной рамкой, по четыре фотографии в ряд. Под снимками указаны ID, число рамок и ссылки на оригиналы. Галерея работает без интернета.
- [Фотографии Контеста](contest_gallery.html): 400 изображений из `dataset.jsonl`, по четыре в ряд. Изображения загружаются по исходным ссылкам iNaturalist; просмотр использует интернет-соединение.

GitHub отображает исходный HTML. Сохранённые файлы галерей открываются в браузере как страницы.

## Локальная сборка галереи

[scripts/build_annotation_gallery.py](scripts/build_annotation_gallery.py) формирует галерею по JSON-разметке и локальным оригиналам из `images/`. Сборка использует Pillow; параметр `--images` задаёт каталог фотографий. Зависимости сбора данных перечислены в [requirements-data.txt](requirements-data.txt).

```bash
python scripts/build_annotation_gallery.py
```
