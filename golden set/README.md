# golden set
400 уникальных фото, 241 рамка: 357 исходных ответов, одобренных ревьюерами, и 43 ответа после переразметки. Для 17 пересечений использована новая разметка.
По решению заказчика последние 43 ответа включены как есть независимо от ревью: 8 одобрено, 35 отклонено. Известные ошибки не исправлены. Название набора не означает независимую проверку всех ответов.
Файл dataset.jsonl содержит одну запись на фото. image и image_url — ссылки на оригиналы iNaturalist. boxes — нормализованные [x, y, width, height]; annotations — исходные рамки p1/p2. reference_image_width и reference_image_height — размеры локальных копий, а не оригиналов.
Статусы: FOUND — 220, NONE — 179, UNCERTAIN — 1. UNCERTAIN нельзя считать отрицательным примером. annotation_source указывает источник разметки, review содержит голоса ревьюеров без изменения ответов. Сами изображения не включены; доступны ссылки и метаданные авторства.
